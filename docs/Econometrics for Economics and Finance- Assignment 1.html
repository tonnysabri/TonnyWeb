(a) Check that 𝑓𝑋 (𝑥) is a true probability distribution.

\[ \frac{1}{12} > 0 \quad \text{for all } x \in \{1, 2, \dots, 12\} \]

\[ \sum\limits_{x=1}^{12} f_X(x) = \sum\limits_{x=1}^{12} \frac{1}{12} = 12 \times \frac{1}{12} = 1 \]

Since both conditions are satisfied f(x) is a valid probability mass function.

(b) Compute the expected value of 𝑋.

\[ E[X] = \sum_{x=1}^{12} x \cdot f_X(x) \]

\[ E[X] =\sum_{x=1}^{12} x = \frac{12(12+1)}{2} = \frac{12 \times 13}{2} = 78 \]

\[ E[X] = \frac{1}{12} \times 78 = \frac{78}{12} = 6.5 \] c) Compute the variance of 𝑋.

\[ Var(X)=E[X^2]−(E[X])^2 \]

\[ E[X^2] = \sum_{x=1}^{12} x^2 \cdot f_X(x) = \frac{1}{12} \sum_{x=1}^{12} x^2 \ \]

\[ \sum_{x=1}^{12} x^2 = \frac{12(12+1)(2 \times 12 + 1)}{6} = \frac{12 \times 13 \times 25}{6} = 650 \]

\[ [ E[X^2] = \frac{650}{12} = \frac{325}{6} \]

\[ \text{Var}(X) = \frac{325}{6} - \left(\frac{13}{2}\right)^2 = \frac{325}{6} - \frac{169}{4} \]

\[ \text{Var}(X) = \frac{650}{12} - \frac{507}{12} = \frac{143}{12} \approx 11.92 \]

question 7

a) Define 𝑓(𝑥) in R

f <- function(x) { (1/9) * x^2 }

b) Integrate 𝑓(𝑥) over the interval [0,3].

\[ \int_{0}^{3} \frac{1}{9}x^2 \, dx = \frac{1}{9} \int_{0}^{3} x^2 \, dx \]

\[ = \frac{1}{9} \left[ \frac{x^3}{3} \right]_{0}^{3} \]

\[ = \left[ \frac{x^3}{27} \right]_{0}^{3} \]

\[ = \left( \frac{3^3}{27} \right) - \left( \frac{0^3}{27} \right) \]

\[ = \frac{27}{27} - 0 = 1 \]

(c) Compute the expected prison sentence.

\[ E[X] = \int_{0}^{3} x \cdot f(x) \, dx = \int_{0}^{3} x \left( \frac{1}{9} x^2 \right) \, dx = \int_{0}^{3} \frac{1}{9} x^3 \, dx \]

\[ \int \frac{1}{9} x^3 \, dx = \frac{1}{9} \left( \frac{x^4}{4} \right) = \frac{x^4}{36} \]

\[ E[X] = \left[ \frac{x^4}{36} \right]_{0}^{3} = \frac{3^4}{36} - 0 = \frac{81}{36} = 2.25 \text{ years} \]
